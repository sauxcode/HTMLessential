102 Etiquetas HTML

Número Nombre de la Etiqueta Descripción Ejemplo de Uso Elemento Adicional
1 <a> Define un hipervínculo. <a href="https://www.example.com">VisteUnEjemplo</a> Se puede agregar el atributo target="_blank" para abrir el enlace en una nueva pestaña.
2 <p> Define un párrafo de texto. <p>Este es un párrafo.</p> Puede contener otros elementos en línea como <a>, <strong>, <em>.
3 <img> Incrusta una imagen en la página. <img src="imagen.jpg" alt="Descripción de la imagen"> Importante incluir el atributo alt para accesibilidad.
4 <div> Define una sección o contenedor en el documento. <div>Contenido del div</div> Usualmente usado para aplicar estilos o agrupar otros elementos.
5 <h1> Define el encabezado más importante en la página. <h1>Este es un Encabezado</h1> Los encabezados van desde <h1> (más importante) hasta <h6> (menos importante).
6 <!DOCTYPE html> Indica al navegador que el documento está basado en el estándar HTML5. <!DOCTYPE html> <!--Este elemento va incluso por encima del encabezado, especificamente, en la primer línea--> Este es el estándar actual que satisface las necesidades de aplicaciones web modernas, mientras que HTML a secas se considera más obsoleto y carece de muchas características avanzadas.
7 <html> Representa la raíz de un documento HTML. <html>Aquí va toda la página</html> Todos los demás elementos de la estructura HTML deben ser recogidos dentro de estas etiquetas.
8 <head> Representa una colección de metadatos acerca del documento, incluyendo enlaces a, o definiciones de, scripts y hojas de estilo(css). <head>Aquí va el encabezado del documento</head> El resto de etiquetas de metadatos, irán recogidas dentro de las etiquetas de apertura y cierre del head. Importante explicar que estos metadatos del documento, es información para el navegador y no contenido que será visible en la página web. A excepción de la etiqueta <title>que veremos a continuación.
9 <title> Etiqueta usada para definir el título de la página web. <title>Aquí va el título principal de la página</title> Cuando esta etiqueta queda oculta o no se utiliza, la pagina toma como título el nombre del archivo original.
10 <link> Se usa para enlazar recursos externos al documento HTML. <h1>link rel="stylesheet" href="styles.css"</h1> El ejemplo más común son las hojas de estilos CSS.
11 <meta> Etiqueta usada para definir otros metadatos que no se pueden definir con una etiqueta HTML especifica. <meta name="viewport" content="width=device-width, initial-scale=1.0"> Por ejemplo, para definir el autor del sitio, o la descripción del mismo.
12 <style> Etiquetas usadas para introducir código CSS en línea, es decir, en el propio documento HTML <style> Generalmente aquí va el aspecto visual y el estilo de los elementos del documento.</style> Te permite diseñar tu página sin depender de una página aparte enlazada .css, es util si todo lo quieres implementar exclusivamente en el documento html.
13 <body> Todo lo que quieras mostrar en la página web debe ir recogido dentro de estas etiquetas. <body>Contenido visible</body> Representa el contenido principal de la página web.
14 <nav> Usadas para definir el contenido que será la sección de navegación de la web. <nav><a href="index.html">Inicio</a></nav> Facilita la navegación del usuario.
15 <main> Se usa para definir el contenido principal del documento. <main>Contenido principal</main> Solo puede existir uno por documento.
16 <section> Define una sección del documento. <section><h2>Título Sección</h2></section> Usada para dividir el contenido en secciones temáticas.
17 <article> Define contenido independiente de la web. <article><p>Contenido del artículo</p></article> Ideal para publicaciones o blogs.
18 <aside> Contenido adicional de la web. <aside>Contenido relacionado</aside> Generalmente de poca importancia.
19 <footer> Usadas para definir el pie de página. <footer><p>Derechos reservados</p></footer> Contiene información de copyright y enlaces.
20 <hr> Etiqueta utilizada para "romper" entre dos secciones de una web. <hr> Usada comúnmente como separador.
21 <blockquote> Se usan para indicar que el contenido es texto citado. <blockquote>Cita textual</blockquote> Usualmente se usa para citas de otros autores.
22 <ol> Etiquetas para crear una lista ordenada. <ol><li>Elemento 1</li></ol> Usada para listar elementos en un orden específico.
23 <ul> Etiquetas para crear una lista desordenada. <ul><li>Elemento 1</li></ul> Usada para listar elementos sin un orden específico.
24 <figure> Indica una figura ilustrada como parte del documento HTML5. <figure><img src="imagen.jpg"><figcaption>Descripción</figcaption></figure> Usada para incluir imágenes y su descripción.
25 <table> Etiquetas de apertura y cierre de una tabla. <table><tr><td>Celda</td></tr></table> Usada para organizar datos en filas y columnas.
26 <form> Etiqueta de apertura y cierre de un formulario de una página web. <form><input type="text"></form> Usada para recoger información del usuario.
27 <input> Pinta un campo de introducción de datos para el usuario. <input type="text"> Es de las principales etiquetas de un formulario.
28 <button> Etiqueta utilizada para representar un botón en el formulario. <button>Enviar</button> Permite al usuario enviar información.
29 <select> Input que permite una selección entre un conjunto de opciones. <select><option>Opción 1</option></select> Usada para crear menús desplegables.
30 <textarea> Añade un campo al usuario para que pueda introducir texto en varias líneas. <textarea>Texto aquí</textarea> Utilizada para comentarios o descripciones largas.
31 <strong> Etiqueta para definir una palabra o conjunto de ellas como importantes. <strong>Texto importante</strong> Usada para resaltar información crucial.
32 <small> Utilizada para dejar un comentario aparte, como una nota de derechos de autor. <small>Nota de derechos de autor</small> Generalmente se usa para información no esencial.
33 <cite> Para indicar el título de una obra. <cite>Título de la obra</cite> Usada para referenciar obras literarias o artísticas.
34 <sub> Etiqueta utilizada para representar un subíndice. H<sub>2</sub>O Usada en fórmulas químicas y matemáticas.
35 <sup> Etiqueta utilizada para representar un superíndice. x<sup>2</sup> Usada para potencias y exponentes.
36 <mark> Usada para resaltar texto. <mark>Texto resaltado</mark> Utilizada para enfatizar partes importantes del texto.
37 <br> Etiqueta utilizada para crear un salto de línea. <br> Usada para separar líneas de texto.
38 <svg> Se usa para llamar a una imagen vectorizada. <svg><circle cx="50" cy="50" r="40"></circle></svg> Permite crear gráficos vectoriales.
39 <iframe> Sirve para anidar otro documento HTML dentro del documento principal. <iframe src="pagina.html"></iframe> Usada para incrustar contenido de otras páginas.
40 <embed> Usada para integrar una aplicación o contenido interactivo externo. <embed src="archivo.swf"> Utilizada para contenido multimedia no HTML.
41 <object> Utilizada para llamar a un recurso externo de la web. <object data="archivo.pdf"></object> Puede ser tratado como una imagen o recurso externo.
42 <video> Se usa para reproducir video en la página web. <video controls><source src="video.mp4"></video> Permite incluir archivos de video y audio.
43 <audio> Usada para cargar en una web un archivo de audio. <audio controls><source src="audio.mp3"></audio> Permite incluir archivos de audio en el contenido.
44 <source> Permite a autores especificar recursos multimedia alternativos. <source src="video.mp4" type="video/mp4"> Usada dentro de etiquetas de video o audio.
45 <caption> Usada para indicar el título de la tabla. <table><caption>Título de la tabla</caption></table> Ayuda a describir el contenido de la tabla.
46 <option> Etiqueta ligada a <select>. Permite añadir diferentes opciones al <select>. <option value="2">Opción 2</option> Define una opción dentro de un menú desplegable.
47 <progress> Representa el progreso de una tarea. <progress value="50" max="100"></progress> Usada para mostrar el avance de una operación.
48 <meter> Usada para representar un valor escalar dentro de un rango conocido. <meter value="0.7" min="0" max="1"></meter> Utilizada para mostrar una medida dentro de un rango.
49 <header> Se usan para definir la cabecera de la página web. Suele contener el logotipo, menú de navegación, etc. <header><h1>Mi Sitio Web</h1></header> Ideal para agrupar elementos de introducción o navegación principal.
50 <pre> Usada para pegar texto manteniendo el pre formato propio del texto. <pre>Texto con espacios</pre> Muestra el texto con una fuente monoespaciada y respeta saltos de línea.
51 <li> Etiquetas que recogen el contenido de un elemento de una lista, sea ordenada o no. <li>Elemento de lista</li> Debe estar siempre dentro de una etiqueta ul u ol.
52 <dl> Usada para crear una lista de definiciones. <dl><dt>Término</dt><dd>Descripción</dd></dl> Contiene grupos de términos (dt) y descripciones (dd).
53 <dt> Representa un término definido por la siguiente etiqueta <dd> <dt>HTML</dt> Se utiliza dentro de una lista de descripción (dl).
54 <dd> Se usa para definir los términos listados antes que él. <dd>Lenguaje de marcado de hipertexto.</dd> Proporciona la definición o valor del término dt previo.
55 <figcaption> Utilizada para definir la leyenda de una figura. <figcaption>Figura 1. Descripción de la imagen.</figcaption> Se coloca de manera interna dentro de un bloque figure.
56 <span> Etiqueta HTML sin ningún significado específico. Se usa conjuntamente con los atributos «class» o «id» para atribuirle ciertas características. <span class="resaltado">texto</span> Es un contenedor en línea (inline) útil para aplicar estilos CSS personalizados.
57 <colgroup> Etiqueta utilizada para agrupar dos o más columnas de una tabla. <colgroup><col span="2" style="background:gray"></colgroup> Permite aplicar estilos de forma masiva a columnas completas.
58 <tbody> Usada para describir los datos concretos de una tabla. <tbody><tr><td>Datos</td></tr></tbody> Agrupa el cuerpo principal del contenido de la tabla.
59 <thead> Indica el bloque de filas que describen las etiquetas de las columnas de la tabla. <thead><tr><th>Título</th></tr></thead> Define la sección de cabecera superior de una tabla.
60 <tfoot> Indica los bloques de filas que describen los resúmenes, o datos totales de una columna de una tabla. <tfoot><tr><td>Total</td></tr></tfoot> Se sitúa en la parte inferior para mostrar conclusiones o sumatorias.
61 <tr> Se usa para indicar una fila de celdas de una tabla. <tr><td>Celda</td></tr> Contenedor horizontal para celdas de encabezado o de datos.
62 <td> Usada para definir una celda de una tabla. <td>Contenido de celda</td> Contiene los datos básicos e individuales de la tabla.
63 <th> Etiqueta que se usa para definir el encabezado de una celda <th>Nombre</th> Muestra el texto centrado y en negrita por defecto.
64 <fieldset> Etiqueta que representa un conjunto o agrupación de elementos de un formulario. «Pinta» un recuadro alrededor de las etiquetas que estén contenidas dentro del <fieldset> <fieldset>...</fieldset> Sirve para organizar lógicamente los apartados de un formulario extenso.
65 <legend> Etiqueta ligada a <fieldset>. Indica el título del <fieldset> <legend>Datos Personales</legend> Aparece sobre la línea exterior del recuadro generado por fieldset.
66 <label> Se usa para definir el nombre o título de un control del formulario. <label for="nombre">Nombre:</label> Mejora la accesibilidad al enlazar el texto con su respectivo input.
67 <optgroup> Permite agrupar opciones relacionadas dentro de un menú desplegable select. <optgroup label="Frutas"><option>Manzana</option></optgroup> Ayuda visualmente a segmentar listados muy extensos.
68 <datalist> Contiene un conjunto de opciones predefinidas para un control input. <datalist id="navegadores"><option value="Chrome"></datalist> Crea una función de autocompletado nativo mientras el usuario escribe.
69 <output> Representa el resultado de un cálculo matemático o script. <output name="resultado">100</output> Muy vinculada con elementos de formulario interactivos mediante JavaScript.
70 <details> Crea un widget interactivo de revelación de información que el usuario puede abrir o cerrar. <details><summary>Ver más</summary>Contenido oculto</details> Excelente para secciones de Preguntas Frecuentes (FAQs) nativas.
71 <summary> Define el encabezado visible y cliqueable para el elemento <details>. <summary>Título del desplegable</summary> Al hacer clic sobre él, despliega u oculta el resto de la información.
72 <time> Representa un período de tiempo específico, una fecha exacta o una hora del día. <time datetime="2026-10-06">Hoy</time> Permite a motores de búsqueda leer fechas de manera estructurada y legible.
73 <q> Se utiliza para incrustar una cita textual corta en línea (inline). <q>Pienso, luego existo</q> El propio navegador se encarga de encerrar el texto entre comillas automáticamente.
74 <dialog> Representa una caja de diálogo, ventana emergente (popup) o componente modal. <dialog open>¡Hola! Este es un mensaje modal.</dialog> Se puede controlar nativamente mediante JavaScript con .showModal().
75 <template> Contenedor para almacenar fragmentos de código HTML que no se renderizan al cargar la página. <template id="plantilla"><p>Contenido clonable</p></template> Es la base para instanciar elementos repetitivos dinámicamente con JavaScript.
76 <slot> Un marcador de posición dentro de un Web Component (Shadow DOM) que puedes llenar con tu propio marcado. <slot name="mi-texto">Texto por defecto</slot> Esencial en el desarrollo avanzado de interfaces modulares modernas.
77 <canvas> Se utiliza para dibujar gráficos en 2D o animaciones 3D sobre la marcha mediante scripts. <canvas id="lienzo" width="200" height="200"></canvas> Ampliamente usado para videojuegos de navegador y gráficos estadísticos.
78 <noscript> Define un contenido alternativo para los usuarios que tienen JavaScript desactivado en el navegador. <noscript><p>Este sitio requiere JavaScript para funcionar.</p></noscript> Importante para mantener una correcta experiencia de usuario y accesibilidad.
79 <script> Se utiliza para incrustar o hacer referencia a código ejecutable, generalmente JavaScript. <script src="app.js"></script> Aporta dinamismo, lógica e interactividad al sitio web.
80 <map> Se utiliza junto con la etiqueta <area> para definir un mapa de imágenes interactivo. <map name="mapa-link">...</map> Permite enlazar diferentes secciones de una sola imagen a distintas URLs.
81 <area> Define las zonas con enlaces dentro de un mapa de imágenes creado con <map>. <area shape="rect" coords="0,0,50,50" href="link.html" alt="Zona"> Admite figuras geométricas como rectángulos, círculos o polígonos.
82 <track> Se utiliza dentro de las etiquetas <audio> o <video> para especificar subtítulos o pistas de texto. <track src="subtitulos.vtt" kind="subtitles" srclang="es" label="Español"> Fundamental para cumplir las normativas globales de accesibilidad web.
83 <picture> Contenedor flexible que permite definir múltiples fuentes de imágenes basadas en reglas de Media Queries. <picture><source srcset="grande.jpg" media="(min-width: 800px)"><img src="peque.jpg" alt="Responsive"></picture> Herramienta clave para el diseño web responsive óptimo (imágenes adaptativas).
84 <col> Especifica las propiedades comunes a cada columna dentro de un elemento <colgroup>. <col style="background-color:yellow"> Evita tener que dar formato de manera individual a cada celda (td).
85 <address> Indica que el texto contenido provee información de contacto para una persona u organización. <address>Escrito por Juan<br>Visítanos en: Ejemplo.com</address> Suele renderizarse visualmente en letra cursiva (itálica) por defecto.
86 <em> Marca el texto con un énfasis suave, cambiando su significado tonal. <em>Esto es importante</em> El navegador lo muestra comúnmente en cursiva. Aporta valor semántico.
87 <i> Representa un texto que se aparta del estilo normal (términos técnicos, pensamientos). <i>Homo sapiens</i> Visualmente idéntica a em, pero sin añadir peso o importancia semántica.
88 <b> Resalta un fragmento de texto con fines utilitarios sin conferirle mayor importancia. <b>Palabra clave</b> Aplica un estilo en negrita estándar (útil para listados tipográficos).
89 <u> Representa un texto con una anotación no textual integrada (como palabras mal escritas). <u>Texto subrayado</u> Aplica un subrayado tradicional continuo sobre la línea de base.
90 <s> Muestra textos que ya no son correctos, precisos o relevantes. <s>Precio original: $50</s> Dibuja una línea horizontal cruzando el centro del texto (tachado).
91 <del> Representa texto que ha sido explícitamente borrado o removido de un documento. <del>Texto antiguo</del> Suele trabajar de la mano con la etiqueta ins para marcar revisiones de código o textos.
92 <ins> Representa una sección de texto que ha sido añadida recientemente al documento. <ins>Nuevo texto añadido</ins> Por defecto, los motores de los navegadores web lo muestran subrayado.
93 <abbr> Representa una abreviatura o un acrónimo dentro del documento de hipertexto. <abbr title="Organización de las Naciones Unidas">ONU</abbr> Muestra una descripción flotante cuando el usuario posa el ratón encima.
94 <code> Muestra un fragmento corto de código de computadora u orden de terminal. <code>console.log("Hola");</code> Usa tipografía monoespaciada de manera nativa para facilitar su legibilidad.
95 <kbd> Representa una entrada de datos por teclado o comandos directos del usuario. <kbd>Ctrl + C</kbd> Se le suele dar estilos CSS simulando el aspecto físico de una tecla.
96 <samp> Representa una muestra de salida (output) generada por un programa informático o sistema. <samp>Error 404: Not Found</samp> Al igual que code, cambia de forma automática el estilo a fuente monoespacio.
97 <var> Define el nombre de una variable en una expresión matemática o de programación. <var>x</var> = <var>y</var> + 2 Por convención tipográfica de los navegadores, se muestra en letra itálica.
98 <dfn> Indica que el texto circundante o inmediato define el término que contiene. <El sol>es una estrella gigante. Representa la instancia de definición principal de un concepto.
99 <data> Enlaza un contenido legible por humanos con una traducción legible por máquinas (datos). <data value="9780134685991">Libro de HTML5</data> Muy útil para añadir IDs de productos, códigos de barras o SKU sin romper el texto.
100 <bdi> Aísla una parte del texto que podría estar formateada en una dirección de lectura diferente (ej. Árabe). <bdi>إياد</bdi>: 4 posts Evita errores de renderizado bidireccional en cadenas dinámicas de texto mixto.
101 <base> Especifica la URL base y/o el objetivo (target) para todos los enlaces relativos contenidos en un documento. <base href="https://ejemplo.com" target="_blank"> Debe ir colocada obligatoriamente dentro del elemento head y solo puede haber una por documento.
102 <wbr> Indica una oportunidad de salto de línea (Word Break Opportunity) en textos muy largos. <p>EsteEsUnTextoExtremadamenteLargo<wbr>QueSePuedeDividir.</p> El navegador solo aplicará el salto si el contenedor se queda sin espacio horizontal.
